import { Card, CardGrid, LinkCard } from '@astrojs/starlight/components';

```julia
using Equations

disk = Relation(<=, x -> x[1]^2 + x[2]^2, 1)    # f(x) ≤ 1
issatisfied(disk, [0.5, 0.5])                    # true

sys = EquationSystem(Equation(x -> x[1]^2 + x[2]^2, 1), Equation(x -> x[1], x -> x[2]))
solve(sys, [1.0, 0.5]).u                         # ≈ [0.70711, 0.70711]
```

## What it does

<CardGrid>
  <Card title="One vocabulary" icon="puzzle">`=`, `≠`, `<`, `≤`, `>` and `≥` between numbers, arrays, functions, symbolic or JuMP expressions.</Card>
  <Card title="Algebra" icon="random">Arithmetic on both sides at once, flipping inequalities where needed; `canonicalize` for optimizers.</Card>
  <Card title="One solve" icon="rocket">Newton, bisection, all roots, closed forms and feasible points for inequalities behind `CommonSolve.solve`; `minimize` and `maximize` under constraints.</Card>
  <Card title="Integrations" icon="seti:julia">Package extensions for ForwardDiff.jl, NonlinearSolve.jl, Symbolics.jl and JuMP.jl.</Card>
</CardGrid>

---
title: Building the docs
description: How the Equations.jl site is built, and how to add an example.
---

The site is an [Astro](https://astro.build) + [Starlight](https://starlight.astro.build) site
in `docs/`, set up with the shared
[max-models starlight-theme](https://github.com/max-models/starlight-theme): `defineDocs` in
`docs/astro.config.mjs` provides the base path, the look, math and the link check.

The theme's notebook and gallery tools run Python, so the Julia parts are generated by
`docs/generate.jl` instead, in the theme's format and with its components:

| Generated | From |
|---|---|
| `src/content/docs/examples/*.mdx`, `public/examples/` | the scripts in `examples/` |
| `src/content/docs/api.mdx` | the docstrings of `Equations` |

The generated files are not committed; CI regenerates them on every build. Everything else under
`docs/src/content/docs/` is written by hand.

## Building locally

You need Julia (1.11 or later) and Node.js (22 or later). In `docs/`:

```sh
julia --project=. -e 'using Pkg; Pkg.instantiate()'   # Equations from .. and the example packages
npm install
npm run generate     # run the examples, write the example and API pages
npm run dev          # live preview at http://localhost:4321/Equations.jl/
npm run build        # the static site in docs/dist, as in CI
```

`npm run dev` and `npm run build` regenerate the pages first.

## Writing an example

An example is a plain Julia script in `examples/`, in a subdirectory that names its group on the
gallery page. Comment lines starting with `# ` are Markdown, everything else is code. Each code
chunk is run in order and shown with what it printed and its value; end a chunk with `;` to hide
the value, and separate two chunks with a bare `#` line. The script starts with a header:

```julia
# # Title of the example
#
# One paragraph: the text on the gallery card and the page description.
#
# thumbnail: x² = 2
# order: 3
#
# More Markdown, with $math$, at the top of the page.

using Equations
```

`thumbnail` is the short text shown on the card and `order` the position of the example in the
gallery and the sidebar (both optional). A script that throws an error fails the build.
Packages an example uses go into `docs/Project.toml`.

## CI

`.github/workflows/docs.yml` runs the generator, builds the site, checks that the main pages
exist, and deploys it to GitHub Pages on a push to `main`. Pull requests build the site
without deploying it. GitHub Pages must be set to deploy from GitHub Actions
(Settings → Pages → Source).
